02 — BTS SIO SISR

IA locale pour la cyber

Un assistant qui connaît la doc de mes outils — pour expliquer une commande ou décrypter une sortie Nmap, sans envoyer de données au cloud.

← Tous les projets

Projet personnel · □ En cours · 2026

Fiche initiale : les détails non présents dans mes notes restent à documenter. Les étapes prévues ne sont pas présentées comme réalisées.

Contexte

Je souhaite exploiter une RTX 3070 pour expérimenter un assistant local à partir de la documentation de mes outils de cybersécurité.

Objectif

Expliquer une commande ou une sortie Nmap en s’appuyant sur la documentation, sans envoyer les données du laboratoire vers un service cloud.

Technologies utilisées

  • RTX 3070
  • LLM local
  • RAG
  • Documentation Nmap
  • Documentation Burp Suite

Étapes prévues / à confirmer

  1. Sélectionner un corpus de documentation.
  2. Tester un modèle compatible avec les ressources disponibles.
  3. Expérimenter la recherche dans les documents.
  4. Comparer les réponses avec la documentation originale.

Difficultés & points de vigilance

Points à mesurer : limites de mémoire, réponses inexactes et qualité de la recherche documentaire. Aucun résultat chiffré n’est revendiqué.

Solutions / démarche

Démarche prévue : tester sur des questions simples, conserver les références et vérifier chaque réponse technique avant utilisation.

Compétences travaillées

  • Documentation technique
  • Notions de RAG
  • Évaluation de réponses
  • Limites des modèles locaux

Bilan

Expérimentation en cours : je présente l’objectif et la méthode, avec des résultats encore à documenter.

Pistes d’amélioration

  • Documenter le modèle retenu.
  • Publier des exemples de réponses vérifiées.
  • Mesurer les ressources consommées.
