03 — BTS SIO SISR

ThinkPad sous Linux

Migration complète d'un ThinkPad X13 vers Ubuntu : tests matériels, Secure Boot, vérification SHA256 de l'ISO, configuration de zéro.

← Tous les projets

Projet personnel · ■ Fonctionnel · 2025

Contexte

Je voulais utiliser mon ThinkPad X13 sous Ubuntu et partir d’une installation que je comprends.

Objectif

Migrer la machine vers Ubuntu 24.04 en vérifiant le support matériel et les étapes d’installation.

Technologies utilisées

  • ThinkPad X13
  • Ubuntu 24.04
  • Secure Boot
  • SHA256

Étapes réalisées

  1. Vérification SHA256 de l’image ISO.
  2. Tests du matériel.
  3. Vérification du comportement avec Secure Boot.
  4. Installation et configuration d’Ubuntu.

Difficultés & points de vigilance

Compatibilité du matériel et comportement de Secure Boot : les points vérifiés dans cette migration. Les messages d’erreur précis restent à documenter.

Solutions / démarche

Vérifier l’image avant l’installation et tester le matériel avant de finaliser la configuration.

Compétences travaillées

  • Installation Linux
  • Vérification d’intégrité
  • Configuration système
  • Diagnostic matériel

Bilan

Migration indiquée comme fonctionnelle dans mes notes de projet. La fiche détaille le périmètre sans inventer de benchmark.

Pistes d’amélioration
