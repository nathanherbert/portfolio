Ce portfolio

Le site que tu lis. Pensé pour évoluer pendant les deux ans du BTS et documenter la progression, pas juste les réussites.

← Tous les projets

Projet personnel · □ En cours · 2025 →

Contexte

Ce site accompagne mes deux années de BTS et rend mes projets accessibles à un enseignant ou à un recruteur.

Objectif

Présenter mon parcours, ma pratique et ma progression dans un site sobre, destiné à GitHub Pages.

Technologies utilisées

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages

Étapes réalisées

  1. Centralisation du contenu.
  2. Création du terminal interactif et de l’effet de loupe.
  3. Passage à une architecture avec pages dédiées.
  4. Conversion de la version React en pages HTML, CSS et JavaScript pour GitHub Pages.

Difficultés & points de vigilance

Conserver le style initial en enrichissant les pages, éviter les liens vides et gérer les accès directs sur un hébergement statique.

Solutions / démarche

Reprendre les pages et les styles existants, puis utiliser JavaScript natif pour les interactions et la validation du formulaire.

Compétences travaillées

  • HTML, CSS et JavaScript
  • Composants React et TypeScript dans la première version
  • Responsive
  • Accessibilité
  • Organisation du contenu
  • Hébergement statique

Bilan

Le portfolio est un projet qui évolue. La publication, les coordonnées réelles et les captures de projets restent à finaliser.

Pistes d’amélioration

  • Publier sur mon domaine github.io.
  • Renseigner les coordonnées vérifiées.
  • Compléter les fiches avec mes propres captures.
