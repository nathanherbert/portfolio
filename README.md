# Portfolio Nathan Herbert

Portfolio d’un étudiant en BTS SIO option SISR. Les pages sont écrites en HTML et partagent une feuille CSS et un fichier JavaScript. Aucun outil de compilation ni installation de dépendances n’est nécessaire.

## Ouvrir ou modifier le site

- Ouvre `index.html` dans ton navigateur. Les liens fonctionnent aussi depuis les fichiers locaux.
- Modifie le texte dans le fichier `index.html` de la page concernée. Les six fiches sont dans `projets/`.
- Le style est dans `assets/style.css`. Le menu mobile, l’horloge, la loupe, le terminal et le formulaire sont dans `assets/site.js`.
- Le formulaire est en mode démonstration. Il valide les champs et affiche une confirmation sans envoyer de message.

## Publier sur GitHub Pages

1. Crée un dépôt public nommé `portfolio` depuis ton compte GitHub.
2. Mets le **contenu du dossier `app`** à la racine du dépôt. Tu dois voir `index.html`, `404.html`, `.nojekyll`, `assets/` et les dossiers des pages au premier niveau.
3. Dans le dépôt, ouvre **Settings → Pages**, puis sélectionne **Deploy from a branch**. Choisis **main** et **/ (root)**, puis clique sur **Save**.
4. Quand GitHub affiche **Visit site**, ouvre le lien dans une fenêtre privée pour vérifier que ton professeur pourra y accéder.

Avec le compte `nathanherbert` et un dépôt `portfolio`, l’adresse attendue est `https://nathanherbert.github.io/portfolio/` une fois la publication terminée.

La procédure complète est disponible dans la [documentation GitHub Pages](https://docs.github.com/fr/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
